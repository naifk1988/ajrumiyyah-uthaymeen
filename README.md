# شرح الآجرومية — ابن عثيمين (كتاب تفاعلي)

موقع ثابت (HTML واحد) يعرض شرح الآجرومية للشيخ محمد بن صالح العثيمين رحمه الله:

- شجرة الأبواب والمسائل، ولوحة علامات الإعراب
- المتن مشكولًا مع إحالة كل فقرة إلى صفحة شرحها، ووضع للتسميع
- قارئ لصفحات الكتاب (`p/1.png` … `p/576.png`) مع علامات وملاحظات
- بحث في نص مستخرج آليًّا (`text.json`)، واختبار من ٤٥ سؤالًا
- الدروس الصوتية (الشرح الثاني، ١٦ درسًا) من أرشيف الإنترنت عبر موقع الفقه في الدين

النشر: يكفي ربط المستودع بـ Vercel (Framework: Other، بلا أمر بناء، ومجلد الإخراج هو الجذر).
